# PROYECTO_GRUPO4
Proyecto desarrollado por el grupo 4 para la materia **Manejo y Configuracion de Software** de la Universidad Tecnica de Ambato, Facultad de Ingenieria en Sistemas, Electronica e Industrial

## Descripcion
La pagina web desarrollada es una plataforma web de entretenimiento digital inspirada conceptualmente en el universo de Spider-Man
El sitio cuenta con una pantalla de bienvenida (Landing Screen) con un botón de acceso directo *"¡BIENVENIDOS!", la cual da paso a un catálogo completo de películas,
Permite la reproducción de contenido multimedia mediante la integración de reproductores en la nube (Google Drive API), maquetado de forma 100% *responsive con un diseño oscuro de neón rojo
El proyecto resuelve el reto de desarrollar una aplicación visualmente atractiva en un entorno de desarrollo colaborativo, permitiendo trabajar en equipo sin conflictos de código mediante la 
metodología *GitFlow* y optimizando el almacenamiento al hospedar los archivos de vídeo pesados en servidores externos.


## Objetivo
Aplicar el modelo de trabajo **GitFlow** mediante el desarrollo de un sitio web basico, simulando un entorno real de desarrollo en equipo 


## Tecnologias utilizadas
- HTML
- CSS3
- JavaScript
- Framework Bootstrap 5
- Integracion Embed de Google Drive (Reproductor Multimedia)

## Estructura de ramas
- `main`: version estable y desplegable del proyecto
- `develop`: rama de integracion de las features en desarrollo
- `feature/*`: una rama por funcionalidad, creada desde `develop`
- `release/*`: preparacion de una nueva version antes de pasar a `main`
- `hotfix/*`: correcion urgente directamente sobre `main`
